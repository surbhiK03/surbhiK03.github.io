# Surbhi Kaushik Portfolio

Personal portfolio of Surbhi Kaushik, Frontend Developer specializing in React, JavaScript, TypeScript, accessible interfaces and performance-focused web applications.

## Tech

- Static single-page site with semantic HTML
- Tailwind CSS via Play CDN with the reference site's dark theme
- Vanilla JavaScript for mobile navigation, active-section highlighting and scroll interactions
- AOS for on-scroll animations and Font Awesome icons

## Run locally

```bash
npm install
npm run build
python3 -m http.server 8080
```

Open http://localhost:8080.
